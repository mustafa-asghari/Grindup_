# Patch Note: REL-002

## Worker personality

Reliability Worker - Production SRE

## Issue

The runner `/execute` handler blocked the FastAPI event loop while Docker SDK work and polling ran synchronously.

## Root cause

`execute_code` is an async FastAPI route, but it directly called `docker_service.run_code(...)`, which performs synchronous Docker operations and sleeps while polling the container.

## Original proof example

```bash
Start a slow /execute request then immediately run time curl -s http://localhost:8080/health.
```

## Original fix location

`apps/runner/main.py` `execute_code` around lines 96-103.

## Original what to change

Use `run_in_threadpool` or make the route sync so FastAPI offloads Docker work.

## Files changed

- `apps/runner/main.py`
- `Agents/stat.json`
- `Agents/patches/REL-002.md`

## Fix made

The patch changed the exact original fix location. `execute_code` now awaits `starlette.concurrency.run_in_threadpool(...)` for the existing `docker_service.run_code(...)` call, leaving request validation, runner token middleware, language/test-case validation, and response construction unchanged.

## Why this fix is minimal

The change only moves the blocking Docker execution call off the event loop. It does not alter the Docker service implementation, add unrelated concurrency policy, change accepted payloads, or change the `/execute` response model.

## Validation attempted

- `python3 -m py_compile apps/runner/main.py` - passed
- `python3 -m json.tool Agents/stat.json >/dev/null` - passed

The original proof example was not rerun because this Worker pass did not start the runner service or execute Docker workloads.

## Result

Docker execution work is dispatched to Starlette's threadpool, so the event loop can continue serving `/health` and other requests while a submission is running.

## Compatibility notes

The FastAPI route remains async and keeps the same `SubmissionResult` response shape. Existing runner token middleware and unsupported-language/no-test-case behavior are preserved.
